## Decided
The README's three showcase clips (route profile with Fresnel zone, a GeoTIFF dropped onto the panel, Wikipedia plus an itinerary) are generated by a script from REAL data: the IGN's WCS answers live, an IGN MDT25 GeoTIFF downloaded when the script runs and rebuilt as a proper tiled COG, and live en.wikipedia.org. The manual's own figures use invented terrain, which is fine to document an interface but would misrepresent the tool in a sales page. The route for the Fresnel clip was chosen by searching the real DEM for a pair where a ridge blocks 10 m towers and a taller tower clears it, so the caption's numbers are true of the data. The one stand-in is the itinerary, said so in the caption, because there is no openrouteservice key in the script; `ORS_API_KEY` makes it ask the real service. The README lost its 348-line feature list (the manual says all of it) and keeps one row per area linking the manual sections.

## Tried and ruled out
Calling `tests/fixtures/ors-route.json` a recorded real response: it is synthetic (the routing rule says so), otherwise the clip would pass invented data off as the service's. Dropping the striped GeoTIFF the IGN returns: ruled out because the application warns in red that it is not a COG and may be slow, which is exactly what a showcase must not show. A smaller window for the Wikipedia clip to save weight: the markers fall under the toolbar and the hover never lands, so it stays 1100x700 at 1.1 MB.

## Watch out
Playwright's `hasText` with a string matches ANY case and any substring, so «Itinerary» matched «Calculate itinerary…» and closed the menu: use anchored regular expressions. In a dense centre the context menu of a marker has one submenu per overlapping layer («Itinerary from ▸»), and a diagonal slide of the cursor from that item crosses «Itinerary to ▸» and opens ITS submenu over the wanted one: move along the row into the submenu first (`pickSub`). «Calculate itinerary» opens over the upper half of the map and a click under it is lost: frame the points in the lower half. The default units in English are nautical miles and feet, so set `setMeasureUnit("km")` and `setAltitudeUnit("m")` in each scene. The data is live, so after each regeneration re-read the numbers the captions state against the frames.

In the code: `tools/demo-scenes.mjs`, `tools/_gif.mjs` (cursor, recorder, encoder shared with `tools/demo-gif.mjs`), `tests/browser/_tiff.mjs` (the TIFF writer, now shared with `tests/browser/cog.mjs`), `media/README.md`, `README.md`.
